How NityaTools PDF tools work

The current PDF utilities process selected document data in your browser with the pdf-lib JavaScript library, which is loaded from the jsDelivr content-delivery network. NityaTools does not intentionally upload your selected PDF files to its own server through these tools.

Password-protected, encrypted, damaged or unusually complex PDF files may not process correctly. Keep a copy of important originals before modifying documents.
