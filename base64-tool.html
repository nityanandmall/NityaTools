🔐 Base64 Encoder / Decoder

What is Base64?

Base64 represents binary data using a limited set of printable characters. It is commonly used when data needs to travel through text-oriented formats, but Base64 is an encoding method, not encryption.

Encode text to Base64

Enter text and select Encode. This page converts Unicode text to UTF-8-compatible data before producing the Base64 representation.

Decode Base64

Paste valid Base64 and select Decode to convert it back to text. Invalid input produces an error message. Do not treat Base64 as a way to securely hide passwords or confidential information.
