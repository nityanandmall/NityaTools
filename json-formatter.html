{ } JSON Formatter & Validator

Format and validate JSON

Paste JSON and choose Format to parse the input and display it with two-space indentation. If the text cannot be parsed as JSON, the validator displays an error instead of formatting it.

Minify JSON

Minify parses valid JSON and serializes it without optional indentation or line breaks. This can make JSON more compact for storage, copying or transmission.

Browser processing

This tool uses the browser's built-in JSON parser and serializer. Avoid pasting secrets or credentials into any online page unless you are comfortable with the environment in which you are working.
