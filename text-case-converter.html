🔤 Text Case Converter

Available text case options

UPPERCASE changes letters to capitals, lowercase changes letters to small letters, Title Case capitalizes the first letter of each detected word, and Sentence case capitalizes the beginning of sentences using basic punctuation rules.

Browser-based text tool

The conversion happens directly in your browser. Results may differ from editorial style guides for names, acronyms, hyphenated words or special punctuation, so review important text before publishing.
