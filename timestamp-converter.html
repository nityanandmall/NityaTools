Date/Time to timestamp

What is a Unix timestamp?

A Unix timestamp represents elapsed seconds relative to the Unix epoch, 1 January 1970 at 00:00:00 UTC. This tool expects timestamp input in seconds, not milliseconds.

Timezone behavior

The timestamp itself represents a point in time. The readable output uses your browser's local timezone because JavaScript's Date.toString() is used. The date-time input is also interpreted in the browser's local timezone before being converted to epoch seconds.
