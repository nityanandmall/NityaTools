➗ Ratio Calculator

Enter two whole numbers to simplify their ratio.

How ratio simplification works

The calculator finds the greatest common divisor (GCD) of both integers and divides each value by that number. For example, 20:30 has a GCD of 10, so it simplifies to 2:3.

This tool is intended for finite integer ratios. Decimal ratios may need to be converted to equivalent whole-number values first.
