💻 Binary / Decimal / Hex Converter

Enter a non-negative integer in one field, then convert it to the other number systems.

Number system conversion

Binary uses digits 0–1, octal uses 0–7, decimal uses 0–9, and hexadecimal uses 0–9 plus A–F. These systems represent the same numeric value using different bases.

Example

Decimal 255 equals binary 11111111, octal 377 and hexadecimal FF.

This tool is intended for non-negative integers that JavaScript can represent reliably. It is not a big-integer or fractional-base converter.
