🎲 Random Number Generator

—

Generate an integer in a range

Enter a minimum and maximum value. The tool rounds the minimum upward and the maximum downward, then selects a whole number including both endpoints.

This tool uses JavaScript Math.random(). It is suitable for casual selections, examples and games, but it is not intended for cryptographic, security, regulated lottery or high-stakes randomness.
