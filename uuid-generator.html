🆔 UUID Generator

What is a UUID v4?

A UUID is a 128-bit identifier commonly used for database records, API objects, sessions and distributed systems. Version 4 UUIDs are generated primarily from random data and use the familiar 8-4-4-4-12 hexadecimal format.

How this generator works

Where available, this page uses crypto.randomUUID(). A browser Web Crypto fallback is used on supported browsers when that convenience method is unavailable.

UUIDs are designed to make accidental collisions extremely unlikely, but they should not be treated as passwords, secrets or authorization tokens.
